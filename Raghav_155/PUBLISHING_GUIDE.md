# Technical Article Typography and Publishing Guide

## Heading Hierarchy
* **Title (`<h1>`):** 32px / 700 weight / Deep Navy (`#1e3c72`).
* **Section (`<h2>`):** 24px / 600 weight / Generous top margin.
* **Sub-section (`<h3>`):** 18px / 600 weight.

## Code Typography
Code blocks and inline snippets utilize monospace font stacks (`Consolas`, `Courier New`) with soft gray background fills and syntax borders.
