# Random Tech Blog

[![HTML5](https://img.shields.io/badge/HTML5-Structured-E34F26.svg?style=flat-square&logo=html5)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-Clean%20Typography-1572B6.svg?style=flat-square&logo=css3)](https://developer.mozilla.org/en-US/docs/Web/CSS)

A minimalist, readable personal engineering blog template designed for technical writeups, tutorials, and computer science reflections.

---

## Overview

Random Tech Blog provides a distraction-free reading experience for developer content. Focuses on typographic hierarchy, readable line lengths, code snippet styling, and responsive readability across mobile and desktop viewports.

---

## Features

* **Readable Typography:** Carefully balanced font scales, line-heights, and contrast ratios.
* **Code Block Formatting:** Clean styling for syntax and developer snippets.
* **Zero Dependencies:** Pure HTML5 and CSS for instant page loads and straightforward customization.
